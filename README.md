## 🔐 Supabase Configuration (Optional)

The application includes an automatic offline-first local storage engine that works instantly without any backend configuration. To connect a live cloud Supabase database, create `.env.local` in this directory:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key
```
